0.0.33 July 12, 2026 Latest

Terminal projects and Code Graph make local-agent work feel more direct.

  • Adds an Orca-style Terminal projects rail with project-aware local-agent workspaces and improved TUI fidelity.
  • Adds opt-in Code Graph support so Ask and Wiki generation can use evidence-backed code knowledge while keeping provider-agnostic runtime paths.
  • Adds provider account and usage status surfaces, plus refreshed Grok, Codex, Claude, and Pi model catalogs that preserve Default and user-owned credentials.
  • Polishes Ask with Codex-style send controls, middle-truncated context chips, scroll fades, follow-up queue handling, drag/drop affordances, and steadier process activity UI.
  • Aligns Tasks agent terminals with desktop terminal spawning, color, and appearance, and fixes Tasks create/run completion flows.
  • Continues the desktop render-boundary refactor with scoped controllers, renderers, runtime facades, and broader regression coverage across Ask, Wiki, Tasks, terminal, sidebar, settings, and project surfaces.
  • Hardens public gallery, sitemap, and crawler routes while keeping public website assets separate from the signed desktop bundle.
  • Ships signed and notarized macOS Apple Silicon DMG plus Tauri updater artifacts for 0.0.33.
